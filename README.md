# 🛒 FreshMart – Online Grocery Shopping Website

FreshMart is a responsive online grocery shopping website developed as part of the E-Commerce TA-2 college project. It provides a simple and user-friendly platform where customers can browse grocery products, search for items, add products to their cart, and complete a simulated checkout process.

## 🌐 Live Website

**[Visit FreshMart](https://simranchawla03.github.io/FreshMart/)**

## ✨ Features

- **Product Catalogue:** Browse a variety of grocery and household products.
- **Search Functionality:** Search for products by name.
- **Product Categories:** Explore products organized into different categories.
- **User Login:** Demo mobile-number login functionality.
- **Shopping Cart:** Add products, view cart items, and manage quantities.
- **Checkout:** Enter the required details and validate checkout information.
- **Simulated Payment:** Demonstrate a sample payment process without real transactions.
- **Order Confirmation:** Display confirmation after completing the order.
- **Quick Delivery:** Displays an estimated delivery time of 10–20 minutes.
- **Responsive Design:** User-friendly interface for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Product interactions, login, cart, checkout, and order flow
- **Git & GitHub** – Version control and source code hosting
- **GitHub Pages** – Website deployment

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SimranChawla03/FreshMart.git
   ```

2. Open the project folder:

   ```bash
   cd FreshMart
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## 🛍️ How to Use

1. Open the FreshMart website.
2. Browse products or search for a specific item.
3. Select a product and click **Add to Cart**.
4. Log in using the demo mobile-number functionality if prompted.
5. Add the product to the cart after logging in.
6. Review your cart and proceed to checkout.
7. Enter the required details and follow the simulated payment process.
8. View the order confirmation.

## ⚠️ Important Note

FreshMart is an academic demonstration project. Login and payment functionalities are simulated and are not connected to a real authentication service, payment gateway, or live inventory system. No real payment is processed.

## 🎯 Project Objective

The objective of this project is to demonstrate the design and development of a basic e-commerce application using front-end web technologies. It illustrates essential online shopping workflows, including product discovery, user interaction, cart management, checkout validation, and order confirmation.
